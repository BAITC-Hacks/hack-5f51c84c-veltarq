# FAQ-бот HackAlem AI

Терминальный бот отвечает на 5 заранее известных вопросов о репетиционном кейсе: время, команда, трек, сдача и призы. Бот загружает данные из `faq.txt`, ищет совпадения по ключевым словам и выводит наиболее подходящий ответ. Если совпадений нет, бот отвечает: `Не знаю`.

## Запуск

Нужен Python 3.10 или новее. Дополнительные библиотеки не требуются.

```bash
python bot.py
```

Для завершения диалога введите `выход`.

## Пример

```text
Вы: сколько времени займёт задание?
Бот: На выполнение этого репетиционного кейса достаточно 30–60 минут.

Вы: какая сегодня погода?
Бот: Не знаю
```

## Что получилось

- 5 пар «вопрос–ответ» хранятся отдельно в `faq.txt`;
- поиск работает по словам из вопроса и списку ключевых слов;
- регистр и знаки препинания не мешают поиску;
- неизвестный вопрос не вызывает ошибку;
- бот работает в цикле до команды `выход`.
